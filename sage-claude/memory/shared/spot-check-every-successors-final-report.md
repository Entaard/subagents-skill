**Spot-check every successor's final report, unconditionally — one command batch, whether or not you suspect it.** The check's value is that it is near-free and always run, not that it catches often: what it finds is reporting drift over work that was itself correct.

- Qualifier: this is the calibration home for `../../SKILL.md` `## Handover`'s standing instruction to run one cheap adversarial spot-check on the successor's final report — that clause carries the instruction, the expectation and the tag; this rule carries the evidence behind them and the price. A clean spot-check is the expected outcome and is never evidence the check was wasted. It is not `point-one-adversarial-pass-at-your-own-fixes` — that one buys a dispatched adversarial unit at medium risk and above; this one is a grep-level batch run at one seat every time. It is not `a-readers-structural-claim-is-a-lead` either — that rule says verify a claim before building on it; this one fixes the seat, the cadence and the price.
- Recogniser: two shapes, both over correct underlying work — figures **transposed** in the summary (per-ledger lint verdicts reported `0,3,0,3,1,10,2,1` against an actual `0,3,1,3,0,10,2,1`), and figures **miscounted** (a report claiming 36 findings against a ledger holding 35 rows and 35 ids).
- Falsifier: three consecutive spot-checks that miss reporting drift a later reader then finds in the same report, or one that cannot be settled inside a single command batch.
