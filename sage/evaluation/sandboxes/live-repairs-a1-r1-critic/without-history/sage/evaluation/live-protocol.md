# Later live protocol

This protocol is frozen before treatment outcomes. It is not evidence that a live trial ran.

1. The independent evaluator selects unseen prompts within `holdout-boundary.json`, creates minimum raw inputs plus check/environment files, then runs `pairing.py prepare CASE_SELECTION --output FROZEN_MANIFEST`. The manifest binds the real prompt, inputs, checks, rubric, environment, protocol, and alternating arm order by path and SHA-256 before either arm starts.
2. Each arm receives a fresh sandbox, the same user task, raw inputs, checks, acceptance criteria, installed Sage procedure, and Astra root model. The treatment lets Sage choose eligible worker routing. The baseline requests Astra for every eligible worker. Worker routing is the only intended difference; this protocol does not compare Sage against an absent-skill workflow and makes no whole-workflow causal claim.
3. The evaluator records requested and observed effective model/effort separately. Missing effective identity, token counts, or monetary cost is JSON null. Actor calls and wall time are reported as limited operational observations, not converted into money.
4. Code and evidence/data are the minimum paired families. The creative smoke additionally requires an actual keyboard flow, two declared viewport inspections, and scoped load/interaction timings. Recovery and promotion scenarios test stale projection/idle-writer handling and reversible corrected knowledge respectively.
5. Role-policy observations are live: whether the root chose an adequate mode, briefs were bounded, reviewers/refuters were independent, only one shared writer was active, findings were dispositioned, and reports preserved unknowns. The deterministic helper does not receive credit for those judgments.
6. A scorer who did not build either output applies every case dimension with hash-bound evidence. Applicable dimensions cannot be null. Non-applicable dimensions are absent because the check artifact fixes applicability. `pairing.py validate RESULTS_JSON --manifest FROZEN_MANIFEST` rejects changed frozen artifacts, missing transcripts/check/score evidence, missing or extra scores, non-finite values, and altered pair/routing identity. Null token or money fields remain valid unknowns and require no unavailable meter.
7. Report per-case arm results and paired differences. State sample size and failures. Do not extrapolate general quality, cost, or savings.

When CLI isolation is selected instead of native collaboration, record the Codex version and use a fresh call with `codex exec --ephemeral --json --ignore-user-config --output-schema ...`; pin the treatment skill and sandbox explicitly in the actor packet. This is an execution option, not a required meter or a reason to weaken the actor-information boundary.
